## 3 Testing

Der Bereich Testing dient der Verwaltung und Durchführung von Tests innerhalb eines Projekts. Hier werden Testfälle, Testpläne und Testszenarien organisiert sowie Testergebnisse dokumentiert.

Die Funktionen unterstützen insbesondere die strukturierte Planung, Durchführung und Nachverfolgung von Tests während der Entwicklung und vor Releases.
