## 1 Intro

Power UI DevMan ist ein Tool zur Verwaltung und Übersicht von Tickets, Releases und Testplänen. Die Anwendung wird vor allem im Kontext von Entwicklung und Testing genutzt und bietet eine zentrale Übersicht über aktuelle Tickets, Testaktivitäten sowie anstehende Meilensteine.

Die Anmeldung erfolgt über den Accenture Account. Dazu wird auf „Sign in with Microsoft 365“ geklickt und anschließend die Microsoft-Authentifizierung durchgeführt.

Die Navigation von Power UI DevMan erfolgt über das Menü auf der linken Seite. Die Anwendung ist in mehrere Funktionsbereiche unterteilt, die unterschiedliche Aufgaben innerhalb der Entwicklungs- und Testprozesse abdecken.

#### <span class="circle red">1</span> Menü

Über das linke Menü wird zwischen den Hauptbereichen des Apps navigiert, Administration, DevMan oder Testing.

#### <span class="circle red">2</span> My tickets

Zeigt eine Übersicht der dem aktuellen Benutzer zugeordneten Tickets. Über die Suchfunktion kann gezielt nach Tickets gefiltert werden.
Die detaillierte Verwaltung und Bearbeitung von Tickets ist in Kapitel **2.4 Tickets** beschrieben.

#### <span class="circle red">3</span> Current releases

Übersicht über vorhandene Releases inklusive Status, geplantem Termin sowie Anzahl zugehöriger Tickets und Sprints.
Weitere Informationen zur Verwaltung von Releases sind in Kapitel **2.5 Releases** beschrieben.

#### <span class="circle red">4</span> Current test plans

Zeigt vorhandene Testpläne mit Informationen wie Anzahl der Testfälle, zugehörigem Sprint sowie Start- und Enddatum.

#### <span class="circle red">5</span> Upcoming milestones & events

Zeigt anstehende Projekttermine und wichtige Ereignisse, z. B. geplante Produktivsetzungen oder Projektmeilensteine.
Die Verwaltung von Meilensteinen wird in Kapitel 2.7 Milestones sowie 2.8 Milestones Calendar beschrieben.
